# StockFlow Beta — ระบบจัดการ Stock เสื้อผ้า

## เวอร์ชัน Beta สำหรับทดสอบในเครื่องเท่านั้น
- เริ่มข้อมูลจาก `Stock แก้มบุ๋ม ใหม่(1).xlsx` เท่านั้น
- สินค้าเริ่มต้น301 รายการที่อ่านได้จากชีตทั้งหมด
- ใช้รหัส Vrich/รหัสไลฟ์เป็นรหัสค้นหาหลัก และเก็บ SKU ภายในแยกไว้
- ช่องจำนวนที่ว่างหรืออ่านเป็นจำนวนไม่ได้เริ่มต้นเป็น 0
- ยอดตั้งต้นที่มีจำนวนมากกว่า 0 จะอยู่ที่ หน้าร้าน ส่วน Facebook/TikTok/Shopee เริ่ม 0
- เมนู Import XLSX รองรับไฟล์ตารางแบบหลายชีต/หลายหมวดหมู่ และไฟล์ตารางมาตรฐาน
- ยังไม่มีระบบบัญชีผู้ใช้หรือการจำกัดสิทธิ์ CEO จริง เมนู Import จึงยังไม่ปลอดภัยสำหรับใช้งานจริง
- ยังไม่เชื่อมต่อ Cloud; ข้อมูลอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `stock-management-v1`
3. เปิด Terminal/Command Prompt ในโฟลเดอร์นั้น แล้วรัน `python -m http.server 8000`
4. เปิด Chrome ไปที่ `http://localhost:8000`

## สำคัญ
- เมื่อเปิดเวอร์ชัน Beta นี้ ระบบจะใช้ storage key ใหม่ และลบ localStorage key เก่าที่รู้จักของ StockFlow เพื่อไม่ให้โหลดข้อมูลทดสอบเก่ากลับมา
- การลบนี้ทำเฉพาะ key ที่ระบุในแอป ไม่ได้ล้างข้อมูลเว็บไซต์อื่นในเบราว์เซอร์
- ข้อมูลชุดนี้เป็น Beta เท่านั้น เมื่อพร้อม Final ควรเริ่มใหม่จากไฟล์ Final ที่ยืนยันแล้ว
- Vrich Code ที่ซ้ำกันจะแสดงสินค้าแต่ละรายการแยกกัน โดย SKU ภายในจะมี suffix เพื่อไม่ให้ชนกัน
